# User access and user types

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Overview of managing users across the agency and sub-accounts.

- Sub-account users are managed in Settings → My Staff; they also appear in the agency's team list.
- Agency-type users can reach every client account; account-type users only the accounts selected for them.
- Name, login email, phone, password and permissions can be edited; users can be deleted.
