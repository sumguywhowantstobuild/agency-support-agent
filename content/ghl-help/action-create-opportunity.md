# Create Opportunity action

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Describes the workflow action that creates a new opportunity in a chosen pipeline and stage.

- Settings include pipeline, stage, opportunity name, source, status, value and custom fields; name defaults to the contact's name, status to Open, value to 0.
- With duplicates not allowed, no new opportunity is created if the contact already has one; it doesn't update the existing one either.
- With duplicates allowed, a contact can have several opportunities.
- It needs a contact in the workflow; the owner depends on the account's opportunity settings.
