# Troubleshooting login problems

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Lists common login problems and fixes.

- 2FA codes: check spam for email codes; if texts can't be sent, an agency admin adds the user's phone number.
- "User does not exist in this Agency": the user is logging in on the wrong address or isn't set up in that agency.
- Stuck pages or unknown errors: clear the site's cookies and data; VPNs and some internet providers' security features can block the login.
