# A phone number's incoming call settings

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Describes the settings that decide where a number's calls go.

- Open the number's three-dot menu → Edit Configuration.
- Calls can go to an IVR or workflow, team members, an external phone number, Voice AI, and a forwarding number.
- The incoming call timeout sets how long it rings before moving on; about 20 seconds is suggested.
- Too long a timeout can let a phone's own carrier voicemail answer, which can mark the call as completed instead of voicemail.
