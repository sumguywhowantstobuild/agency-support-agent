# Pipeline Stage Changed trigger

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Describes the trigger that fires when an opportunity moves to a different pipeline stage.

- Filters include In Pipeline, Pipeline Stage, Assigned To, Tag, Lead Value, Lost Reason and Status.
- Dragging a card by hand fires it, as long as the filters match; moving back to an earlier stage fires it again.
- It only reacts to moves as they happen, not to past moves.
- Independent of the Opportunity Created and Status Changed triggers; a workflow can use several triggers.
