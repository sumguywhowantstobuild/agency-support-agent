# Payment providers per channel

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Explains choosing which payment provider each kind of checkout uses.

- Payments → Integrations → Configure Providers.
- Channels include funnels, forms, stores, calendars, invoices, payment links, courses and more; a channel setting overrides the default provider.
- Live and Test can be configured separately.
- If a channel's preferred provider is disconnected on the Integrations page, that channel falls back to the default provider; after reconnecting, select it for the channel again. This is about disconnecting, not failed payments.
- PayPal plus one other provider can be used together.
