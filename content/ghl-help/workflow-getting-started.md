# Getting started with workflows (and basic troubleshooting)

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Introduces workflows and gives a short troubleshooting routine for a workflow that doesn't behave as expected.

- Test with a contact that has never been in the workflow, so earlier enrolment or re-entry rules don't confuse the result.
- Confirm the contact meets every trigger condition and filter.
- Check the re-entry setting when the same contact should be able to enter again.
- If it works in test but not live, compare the real trigger event with the test.
- Read the execution history for skipped steps and errors; when escalating, include the contact, workflow, timing, screenshots and logs.
