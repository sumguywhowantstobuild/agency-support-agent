# Linked calendars and conflict calendars

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Explains the two ways an external calendar (Google, Outlook) works with GHL calendars.

- Set in Settings → Calendars → Connections: add the external calendar, then configure it.
- Linked calendar: shows external events in GHL and, with Write Back Appointments on, pushes GHL bookings to the external calendar.
- The article separates default sync from two-way sync; it describes two-way sync as able to create contacts and appointments from external events and to start workflows.
- Conflict calendar: busy events block availability in GHL but don't create appointments.
- Missing syncs usually mean no linked calendar selected, write-back off, or a broken connection that needs Reconnect.
