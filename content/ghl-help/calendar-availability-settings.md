# Calendar availability settings

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Explains the settings that decide which times a calendar offers.

- Slot duration (appointment length), slot interval (how often a slot starts) and buffer time around appointments.
- Appointments per slot (for group bookings) and per day (a daily cap).
- Minimum scheduling notice (how soon someone can book) and date range (how far ahead).
- Office hours set when booking is possible; existing appointments outside newly reduced hours typically stay booked.
- For buffer, slot interval and date range, HighLevel suggests separate calendars when appointment types need different values.
