# Update Appointment Status action

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Describes the workflow action that changes an appointment's status.

- Statuses: New, Confirmed, Cancelled, Showed, No-show and Invalid.
- An appointment trigger supplies the booking to change; with any other trigger, the action picks that contact's latest appointment.
- Showed and No-show aren't pushed to external calendars, to avoid notifying attendees.
