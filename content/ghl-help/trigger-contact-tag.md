# Contact Tag trigger

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Describes the trigger that starts a workflow when a tag is added to or removed from a contact.

- Filters choose tag added, tag removed, or a specific tag; with no filter it fires on both adding and removing.
- Fires for tags added by hand (single or bulk), by workflow actions, by CSV imports with a tags column, and by integrations such as Zapier.
- Integrations can only add tags this way, so removal-based workflows won't fire for them.
