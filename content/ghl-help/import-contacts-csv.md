# Importing contacts and opportunities from CSV

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Step-by-step for CSV imports of contacts, opportunities or both.

- Only users with Admin access can import contacts. Start from Contacts → Smart Lists → Import Contacts (or Import on the Opportunities page).
- Choose Create, Update, or Create & Update; map each column; optionally skip unmapped columns and tick Don't update Empty Values.
- At the end you can create a smart list, add everyone to a workflow, or add tags to everyone.
- A DND column applies DND to all channels.
- Track the import on the Bulk Actions page and read its errors there.
