# Setting up a dedicated email sending domain

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Step-by-step for giving a sub-account its own email sending domain. Applies to LC Email only.

- Settings → Email Services → Dedicated Domain and IP → Add Domain.
- Use a subdomain such as mg.yourbrand.com.
- GHL can add the DNS records automatically, or they're copied to the DNS host by hand; verification can be forced.
- DNS changes can take up to 24 hours; if it's longer, recheck the records.
- Different domains can be used for different kinds of email.
