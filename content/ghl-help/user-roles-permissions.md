# User roles and permissions in a sub-account

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Explains how to add users and control what they can see and do.

- Settings → My Staff → + Add Employee (or edit a user) → Roles and Permissions.
- Admin: administrative access, subject to configured permissions. User: restricted access with chosen permissions.
- Only Assigned Data limits a user to the contacts, opportunities and tasks assigned to them, and the appointments linked to them.
- Modules can be switched on or off per user; permissions can be copied from another user.
