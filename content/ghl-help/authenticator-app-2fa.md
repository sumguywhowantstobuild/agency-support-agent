# Authenticator app sign-in codes (2FA)

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Explains using an authenticator app for sign-in codes.

- Works with apps such as Google Authenticator, Microsoft Authenticator and Authy, alongside phone and email codes.
- Set up in My Profile with a QR code or manual key.
- Backup codes (10 at a time, each usable once) recover access if the phone is lost.
- Only the user can set it up; admins can't do it with Login As.
