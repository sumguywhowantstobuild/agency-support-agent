# Workflow builder walkthrough (Draft and Publish)

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Tours the workflow builder: canvas, triggers, actions, integration steps, stats and testing.

- Triggers are added with Add New Trigger and actions with the + button; integration-powered steps stay locked until the account is connected.
- Stats View shows trigger enrolment (Attempted, Matched, Unmatched) and message metrics; Test Workflow runs it for a chosen contact.
- Publishing is needed for live automation: a Draft workflow doesn't run from real triggers, though it can still be run with Test Workflow. Contacts waiting in a step stay where they are when a workflow is set back to Draft.
- Edits only affect steps contacts haven't reached yet; repeated tests with the same contact aren't fully reliable.
