# Opportunity Status Changed trigger

Our summary of a HighLevel help article (checked 2026-10-06). Open the source link for the full steps.

## Summary

Describes the trigger that fires when an opportunity's status changes, for example from Open to Won or Lost.

- Filters include Assigned To, Tag, In Pipeline, Lead Value, Pipeline Stage, and the status it moved from and to.
- It fires every time the status changes, so quick back-and-forth changes can start it several times; add conditions to avoid repeated actions.
